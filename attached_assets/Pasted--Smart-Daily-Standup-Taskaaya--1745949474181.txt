✅ مقدمة:
نريد بناء نظام Smart Daily Standup داخل منصة Taskaaya بحيث:

يُولد بشكل آلي المهام اليومية لكل موظف بناءً على المشاريع والمهام المكلف بها.

يسمح للموظف بتأكيد ما أنجزه اليوم ومراجعة مهامه القادمة.

يوفر للوكالة تقرير يومي مُجمع لكل الفريق لمراجعة الأداء والتواصل مع الفريق بذكاء.

يدعم كتابة ملاحظات من الموظفين أو إضافات لتوضيح معوقات أو تعليقات.

🧠 1. طريقة عمل النظام (Workflow الكامل):
كل يوم في الصباح (أو عند دخول الموظف)،
يقوم النظام أوتوماتيكيًا بتحضير قائمة بالمهام المطلوب تنفيذها لكل موظف بناءً على:

المهام المفتوحة Open Tasks.

الأولوية Priority.

موعد التسليم Due Date.

حالة المهمة.

يتم مراجعة هذه القائمة من قبل مدير الوكالة (Agency Manager)
قبل أن يتم إرسالها للموظفين، حيث:

المدير يقدر يعيد ترتيب الأولويات أو يحذف أو يضيف تسك.

يضغط زر "تأكيد Standup Plan اليومي" → يتم نشر المهام للموظفين.

كل موظف عنده صفحة مخصصة Smart Standup بها:

قائمة بالمهام المطلوب تنفيذها اليوم.

خانة لكل مهمة:

✅ زر "تم الإنجاز" (Mark as Done).

❗ خانة "مشكلة أو تعليق" (optional).

في نهاية اليوم:

الموظف يضغط "إغلاق اليوم".

يتم تسجيل:

ما تم إنجازه ✅.

ما تبقى ➔ يتحول تلقائيًا لمهام الغد.

التعليقات أو المشاكل.

الوكالة تستطيع متابعة Dashboard تلخيصية:

موظف 1: أنجز كذا – متبقي عليه كذا – عنده تعليق كذا.

موظف 2: … وهكذا.

🎯 2. تفاصيل الواجهات (Front-End Requirements):
🏡 صفحة Daily Standup للموظف:
عرض قائمة المهام لليوم (بالترتيب حسب الأولوية والتاريخ).

لكل مهمة:

اسم المهمة.

وصف مختصر.

حالة المهمة (جديدة / جارية / مكتملة).

زر ✅ إنهاء المهمة.

خانة ✏️ إضافة تعليق أو مشكلة.

في آخر الصفحة:

زر "إغلاق اليوم" ➔ Review للنتائج اليومية.

🏡 صفحة Review Standup للوكالة:
جدول بجميع موظفي الوكالة.

لكل موظف:

قائمة المهام المسندة له اليوم.

حالة كل مهمة (أنجز / لم ينجز).

تعليقات الموظف.

إمكانية فلترة حسب:

الموظف.

حالة الإنجاز.

وجود مشاكل أو لا.

زر "تصدير تقرير" PDF أو Excel لكل اليوم.

🔄 3. العمليات الآلية (Automation Rules):
توليد المهام اليومية: أوتوماتيك الساعة 6 صباحًا أو عند دخول النظام.

إرسال المهام للموظفين: بعد موافقة مدير الوكالة فقط.

نقل المهام الغير مكتملة: تنتقل تلقائيًا لليوم التالي في بداية اليوم الجديد.

تحليل التعليقات: AI يمكنه تحليل التعليقات المتكررة واقتراح حلول أو رفع إشعارات لو في مشاكل متكررة.

📋 4. البيانات المطلوبة في الـ Database:
جدول جديد daily_standups
حقل	وصف
id	معرّف تلقائي
employeeId	معرف الموظف
date	تاريخ اليوم
tasks_today	قائمة IDs بالمهام المسندة اليوم
tasks_done	قائمة IDs بالمهام المنجزة
comments	نص تعليقات الموظف
status	مفتوح / مغلق
🔥 5. اقتراحات ذكية إضافية لتحسين التفاعل:
✅ نقطة Gamification:
كل موظف يكمل Standup اليومي يأخذ شارة (Badge) أو نقاط تحفيزية (لو عايز تضيف تحفيز).

✅ ذكاء إضافي للمدير:
في نهاية الأسبوع يظهر Dashboard AI:

أكثر موظف ملتزم.

أكثر المهام التي يتم تأجيلها.

أكثر المشاكل المتكررة.

✅ تذكير ذكي للموظف:
لو الموظف ما عملش Standup آخر اليوم → النظام يبعثله Notification خفيفة.

✅ تقييم يومي سريع:
الموظف يقدر يحط تقييم بسيط في نهاية اليوم (يوم جيد – عادي – صعب).

🏁 النتيجة النهائية لما نطبقه:
كل موظف هيعرف بوضوح هو عليه إيه بالضبط بدون وجع دماغ.

كل مدير وكالة هيتابع يومه بكفاءة بدون ما يضيع وقت في التفتيش اليدوي.

الأداء هيكون شفاف ١٠٠٪، وتقدير التيم هيكون دقيق.

المشاكل بتتسجل بدري قبل ما تتفاقم.
