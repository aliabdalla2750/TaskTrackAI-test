✅ برومبت تنفيذ صفحة Task Details View – منصة Taskaaya
📍 رابط الصفحة:
/dashboard/agency/tasks/:taskId

🎯 الهدف:
إنشاء صفحة مفصلة لعرض بيانات أي مهمة Task داخل النظام، مع إمكانية:

مراجعة المعلومات المرتبطة بها.

العودة للمشروع المرتبطة به.

متابعة الملفات.

تحديث الحالة أو كتابة ملاحظات.

🧱 مكونات الصفحة:
✅ 1. Header – الشريط العلوي:
العنوان الكبير: اسم المهمة.

زر 🔙 "العودة للمشروع" (يربط بـ /dashboard/agency/projects/:projectId).

حالة المهمة الحالية:

مفتوحة (badge بنفسجي).

قيد المراجعة (badge برتقالي).

مكتملة (badge أخضر).

متأخرة (badge أحمر).

شريط Progress (أفقي صغير) لو عايز تمثلها بصريًا.

اسم الموظف المكلف بالمهمة (كـ Badge أو Small Card).

✅ 2. تفاصيل المهمة:
الحقل	الوصف
وصف المهمة	شرح مفصل بما يجب عمله (textarea أو text عادي)
اسم المشروع	يظهر كـ رابط clickable للعودة
تاريخ الإسناد	وقت بدء العمل أو الإرسال
تاريخ التسليم	المطلوب فيه الانتهاء
الموظف المكلف	الاسم + الصورة (اختياري)
الحالة الحالية	Badge + تاريخ آخر تعديل
✅ 3. المرفقات:
قائمة الملفات المرفوعة (PDF, PNG, DOCX...).

لكل ملف:

اسم الملف.

أيقونة نوعه.

زر "تحميل" أو "عرض في نافذة جديدة".

زر "إضافة ملف جديد" (لو حبيت لاحقًا).

✅ 4. تحديث حالة المهمة:
إذا أردت إتاحة تحديث الحالة:

Dropdown: اختر (مفتوحة – تحت المراجعة – مكتملة – متأخرة).

زر "تحديث".

يظهر Toast / Snackbar بعد الحفظ: ✅ "تم تحديث المهمة بنجاح".

✅ 5. اللمسات UX:
لون الحالة يكون واضح جدًا مع أيقونة بجانبه.

كل عنصر قابل للتفاعل يكون فيه Hover + Pointer.

التحميل يتم تدريجيًا مع Skeleton خفيف.

عند تحديث الحالة ➝ يظهر progress indicator لحظي.

🧩 قاعدة البيانات المرتبطة:
جدول tasks
الحقل	الوصف
id	معرف المهمة
title	اسم المهمة
description	وصف
status	مفتوحة / منجزة / تحت المراجعة
assignedTo	معرف الموظف
due_date	التاريخ
projectId	معرف المشروع
جدول task_attachments
الحقل	الوصف
id	معرف الملف
taskId	مرتبط بالمهمة
file_name	اسم الملف
file_url	رابط الملف
file_type	PDF / PNG...
uploaded_by	الموظف
