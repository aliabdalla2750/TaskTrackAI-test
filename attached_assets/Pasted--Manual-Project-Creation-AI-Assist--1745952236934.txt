✅ الجزء الثاني: صفحة إنشاء مشروع يدوي Manual Project Creation + AI Assist
🎯 الهدف:
صفحة احترافية تتيح للمستخدم (مدير الوكالة) إنشاء مشروع يدويًا بسهولة، مع دعم الذكاء الاصطناعي لتوليد:

الأهداف الفرعية.

المهام.

الـ KPIs.

الجدول الزمني (Timeline).

📍 رابط الصفحة:
/dashboard/agency/create-project-manual

🧠 فكرة الصفحة:
الصفحة فيها نموذج ذكي من خطوتين:

الخطوة 1: إدخال يدوي لبيانات المشروع الأساسية.

الخطوة 2 (اختيارية): استخدام AI لتحليل الفكرة وتوليد خطة تنفيذ متكاملة.

🧱 1. مكونات الصفحة
✅ 1.1 النموذج اليدوي الأساسي:
الحقل	النوع	ملاحظات
اسم المشروع	Text	حقل مطلوب
وصف المشروع	Textarea	تفصيل الهدف
اسم العميل	Dropdown	من قاعدة البيانات
تاريخ البداية	Date Picker	
تاريخ التسليم	Date Picker	
نوع المشروع	Dropdown	(اختياري) لتحديد المجال: UI/Dev/Marketing إلخ
🟢 أسفل كل خانة يظهر زر صغير:

✨ "مساعدة من الذكاء الاصطناعي"
لو ضغط عليه → يفتح Popup صغير يساعد المستخدم يولد محتوى الخانة بناءً على مجال الشركة وخدماتها.

✅ 1.2 زر تشغيل الذكاء الاصطناعي:
بعد ملء النموذج الأساسي، يظهر:

💡 "استخدم الذكاء الاصطناعي لتوليد الأهداف الفرعية والمهام تلقائيًا"

زر: ✅ "توليد خطة المشروع الذكية"

عند الضغط:

يتم إرسال اسم المشروع + وصفه + نوعه إلى AI.

✅ 1.3 مراجعة الخطة وتعديلها:
قبل الحفظ النهائي:

المستخدم يراجع الأهداف والتاسكات.

يقدر يعدل يدويًا، يحذف أو يضيف.

زر ✅ "إنشاء المشروع الآن" ➝ يتم حفظه في قاعدة البيانات.

🧠 الذكاء الاصطناعي – كيف بيشتغل:
✅ في الخلفية:
يتم استخدام بيانات العميل، وصف المشروع، ونوعه.

يتم سحب الخدمات المُعرفة مسبقًا في /dashboard/agency/ai-settings.

يتم بناء system_prompt تلقائي زي:

"انت مساعد خبير لمشاريع {UI/Marketing}، العميل يريد تنفيذ {وصف المشروع}. رجاءً اقترح أهداف تنفيذية ووزعها على تسكات واقعية + KPIs"

🤖 Automation Rules:
✅ توليد الأهداف والمهام بشكل منطقي بناءً على نوع المشروع.

✅ عرض خطة Timeline مرئية بعد توليدها (Gantt Style أو جدول).

✅ حفظ خطة AI كمسودة حتى لو المستخدم ما حفظش المشروع النهائي.

✅ دعم "اقتراح تحسين" لاحقًا لكل هدف فرعي.
