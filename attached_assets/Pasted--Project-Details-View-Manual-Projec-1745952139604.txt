صفحة تفاصيل المشروع Project Details View بشكل أكثر ذكاء وتفاعل.

صفحة إنشاء مشروع يدوي Manual Project Creation مع دعم الذكاء الاصطناعي لتوليد الأهداف والتاسكات.

الربط المنطقي بين الشاشات + حركة انسيابية (Animations) + قواعد ذكاء صناعي.

Database Tables لكل مرحلة.

Workflow متكامل + Automation Rules.

وده كله هقسمه على جزئين، وهنبدأ الآن بالجزء الأول:

🔥 الجزء الأول: Project Details View – نسخة احترافية متكاملة
📍 الرابط:
/dashboard/agency/projects/:projectId

🧠 الفكرة:
دي صفحة تفاصيل مشروع، الهدف منها إنها:

تعرض كل تفاصيل المشروع بشكل هرمي:
مشروع ➝ أهداف فرعية ➝ تسكات.

تديك القدرة تتنقل لتفاصيل أي تسك أو ترجع بسهولة.

توضح مين شغال على إيه.

تبين تقدم الإنجاز الفعلي.

وتكون جاهزة للديمو من أول لحظة.

✅ 1. مكونات الصفحة:
✅ 1.1 الشريط العلوي Header:
اسم المشروع بخط كبير.

زر الرجوع للمشاريع.

حالة المشروع (نص أو لون أو شارة).

نسبة الإنجاز الكلية (Progress Ring).

تاريخ البداية / النهاية.

اسم العميل.

✅ 1.2 نظرة عامة (Overview):
وصف المشروع.

عدد الأهداف الفرعية.

عدد التسكات.

عدد التسكات المنجزة.

اسم المدير أو مسؤول المشروع.

✅ 1.3 الأهداف الفرعية (Accordion):
لكل هدف فرعي (Subgoal):

عنوان الهدف.

نسبة التقدم الخاصة به.

تاريخ البداية / النهاية.

تحته قائمة تسكات.

✅ 1.4 المهام داخل كل Subgoal:
لكل Task:

العنوان.

اسم الموظف المكلف.

حالة التنفيذ (badge أو progress).

زر: "عرض التفاصيل".

✅ 1.5 التنقل بين الصفحات:
من التاسك ➝ ترجع للمشروع تلقائيًا من breadcrumb أو زر.

من المشروع ➝ تدخل على التاسك من جوه Subgoal.

🎨 2. اللمسات التفاعلية (UX Enhancements):
عند توسيع أي Subgoal ➝ يستخدم Framer Motion بـ Smooth Expand.

عند hover على أي تاسك ➝ تظليل خفيف مع زر عرض التفاصيل يظهر.

مؤشر تحميل خفيف (Skeleton أو shimmer) لو في تأخير بيانات.

التنقل لا يعيد تحميل الصفحة (SPA navigation).

🧩 3. قاعدة البيانات المطلوبة:
جدول projects
الحقل	النوع	الوصف
id	UUID	رقم المشروع
name	Text	اسم المشروع
description	Text	وصف
clientId	UUID	العميل
agencyId	UUID	الوكالة
status	enum	جاري / مكتمل / متأخر
start_date	Date	تاريخ البداية
due_date	Date	تاريخ التسليم
جدول subgoals
الحقل	النوع	الوصف
id	UUID	معرف الهدف الفرعي
projectId	UUID	المشروع المرتبط
title	Text	اسم الهدف
description	Text	وصف
progress	Number	نسبة التقدم
جدول tasks
الحقل	النوع	الوصف
id	UUID	معرف المهمة
subgoalId	UUID	مرتبط بالهدف الفرعي
title	Text	اسم المهمة
assignedTo	UUID	الموظف المكلف
status	enum	جاري / منجز / متأخر
due_date	Date	تاريخ التسليم
