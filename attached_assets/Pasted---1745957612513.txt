تمام، شغلك في صفحة "مراجعة التقارير اليومية" ممتاز جدًا، وده اللي هنبني عليه دلوقتي علشان نطور ميزة التقرير الأسبوعي للعميل + التقرير الشهري الداخلي للوكالة بشكل احترافي ومتكامل، مع اقتراح دمج ذكي يخلي التقارير كلها تشتغل بانسيابية وبدون تضارب أو تكرار.

✅ تطوير ميزة التقارير الأسبوعية والشهرية داخل Taskaaya
🎯 الفكرة:
إنشاء نظام تقارير موحد ذكي يخرج منه 3 أنواع تقارير:

✅ تقرير يومي داخلي (شغال فعلًا)

✅ تقرير أسبوعي يُرسل للعملاء

✅ تقرير شهري داخلي يُراجع أداء الفريق والتحصيلات

🧩 أولًا: تفاصيل التقرير الأسبوعي للعميل
📍 المكان:
يتم توليده تلقائيًا كل يوم جمعة أو أحد.

يعرض لكل عميل مشاريعهم الفعالة والتقدم فيها.

يتم إرساله عبر:

💬 WhatsApp (QR أو Cloud API)

أو 💌 Email (في النسخة الكاملة لاحقًا)

🧠 محتوى التقرير الأسبوعي:
لكل عميل:
اسم العميل.

كل المشاريع المفتوحة خلال الأسبوع.

لكل مشروع:

اسم المشروع.

نسبة التقدم (progress bar).

عدد المهام المكتملة / المتأخرة.

أحدث تسليم تم.

التاريخ المتوقع لإنهاء المشروع.

رابط مباشر لفتح المشروع.

🟢 مثال للنص المختصر (يُرسل عبر واتساب):

أستاذ محمد،
إليك ملخص العمل على مشروع "تطوير تطبيق XYZ" هذا الأسبوع:
✅ 3 مهام تم تسليمها
⏳ 1 مهمة مازالت جارية
⚠️ لا يوجد تأخير
نسبة التقدم: 75%
👀 راجع كل التفاصيل من هنا: [رابط المشروع]

🔁 طريقة التنفيذ:
العنصر	القيمة
Cron Job	كل جمعة الساعة 9 صباحًا
API	/api/reports/weekly/generate
مصدر البيانات	جدول tasks, projects, clients
طريقة التوصيل	WhatsApp message أو email (JSON → Text)
تسجيل الإرسال	جدول weekly_reports_sent يمنع التكرار
🧩 ثانيًا: تفاصيل التقرير الشهري الداخلي للوكالة
📍 المكان:
يظهر داخل /dashboard/agency/overview أو في صفحة خاصة /dashboard/agency/monthly-report.

📊 محتوى التقرير:
عدد المشاريع المفتوحة خلال الشهر.

عدد المشاريع التي تم إنهاؤها.

عدد المهام المكتملة.

نسبة التأخير (عدد المهام المتأخرة ÷ الكلي).

أكثر الموظفين نشاطًا (حسب عدد المهام).

قائمة بالعملاء النشطين خلال الشهر.

التحصيلات الشهرية (sum of paid invoices).

أكثر مشروع استهلك وقت الفريق.

🔁 طريقة التنفيذ:
العنصر	القيمة
Cron Job	يوم 1 من كل شهر
API	/api/reports/monthly/generate
جدول حفظ البيانات	monthly_reports_cache
طريقة العرض	صفحة مخصصة – مع زر "تصدير PDF"
🔗 دمج ذكي بين الثلاث تقارير:
تقرير	لمن؟	طريقة الدمج
التقرير اليومي	فريق العمل	يظل كما هو – لكل موظف
التقرير الأسبوعي	العميل	يُستخرج من نفس جدول projects + tasks ولكن بفلترة حسب clientId
التقرير الشهري	الوكالة	يُستخرج من نفس الجداول لكن بفلترة month(created_at)
✅ بمعنى:
نفس الـ backend logic → يخدم 3 أنواع تقارير
مع اختلاف المستهدف (Client vs. Internal) + نوع الإرسال (UI vs. WhatsApp)

🖥️ واجهات جديدة مقترحة:
📄 صفحة /dashboard/agency/weekly-reports
جدول بكل العملاء.

لكل عميل: آخر تقرير – نسبة التفاعل – زر إعادة إرسال.

زر "عرض التفاصيل" ➝ يفتح نسخة التقرير.

📄 صفحة /dashboard/agency/monthly-report

جدول بأداء الموظفين.

جدول التحصيلات.

زر "تصدير PDF".
