📩 ابعت له البرومبت ده:

✅ برومبت مفصل لتطوير ميزة إدارة العملاء (Clients & CRM)
أريد تنفيذ ميزة إدارة العملاء بشكل متكامل، وتحديدًا:

🎯 1. صفحة عرض العملاء /dashboard/agency/clients
المطلوب:

عرض العملاء في شكل كروت (Cards)

كل كارت يحتوي على:

اسم العميل

عدد المشاريع المرتبطة

حالة الدفع العامة (منتظم / متأخر / متوقف)

متوسط تقييم العميل (نجوم)

زر "عرض التفاصيل"

زر "تواصل عبر واتساب"

ملاحظات:

حالة الدفع تُحسب تلقائيًا بناءً على الفواتير:

"منتظم": آخر فاتورة مدفوعة في موعدها أو قبل الموعد

"متأخر": فاتورة تأخرت لأكثر من 7 أيام

"متوقف": فاتورتين متتاليتين لم يتم سدادهما

🧾 2. صفحة تفاصيل العميل /dashboard/agency/clients/:clientId
المطلوب:

عرض بيانات العميل الأساسية: الاسم – البريد – الهاتف

قائمة المشاريع المرتبطة بالعميل

سجل الفواتير الخاصة به (مأخوذ من جدول payments)

متوسط تقييم العميل (نجوم) + سجل التقييمات

زر "إضافة تقييم جديد"

ملاحظات داخلية (comments) ➜ لكل ملاحظة:

نص الملاحظة

التاريخ

من كتبها (اسم المستخدم أو الـ ID)

نوع الملاحظة (إيجابية / سلبية / محايدة)

✅ API المطلوبة:
GET /api/clients ➜ قائمة العملاء

GET /api/clients/:id ➜ تفاصيل العميل

POST /api/clients/:id/notes ➜ إضافة ملاحظة داخلية

POST /api/clients/:id/ratings ➜ إضافة تقييم جديد

GET /api/clients/:id/invoices ➜ قائمة الفواتير

🧠 ملاحظات إضافية:
رجاءً تأكد من أن المشاريع والفواتير المرتبطة بالعميل يتم جلبها ضمن الـ details.

يفضل بناء صفحة /clients/:id كـ tabbed view (معلومات عامة – المشاريع – الفواتير – التقييمات – الملاحظات).
