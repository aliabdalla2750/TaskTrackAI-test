🧭 3. النظام الشبكي Grid System:
استخدم Tailwind أو CSS Grid لعمل تقسيم صفوف وأعمدة منظم.

المسافات البادئة والهوامش: p-4, m-4, gap-4 كحد أدنى.

الالتزام بمبدأ التناسق في الحواشي والهوامش بين كل عناصر الصفحة.

🪄 4. التحريك والتفاعل Animations:
✅ عند تحميل الصفحة:
Fade-in لجميع العناصر مع تأخير بسيط باستخدام framer-motion أو Tailwind transition.

✅ عند إرسال رسالة (في الشات الذكي):
تظهر الكتابة كلمة بكلمة (كما في ChatGPT).

إظهار مؤشر كتابه Typing... أثناء الانتظار.

✅ عند الضغط على الأزرار:
تأثير pulse خفيف عند الضغط.

الأزرار تتغير لونها عند الـ hover.

🧩 6. المكونات الرئيسية:
العنصر	وصف التعديل
Navbar	يكون بلون أبيض بخط بارز، فيه أيقونات واضحة وتغيير حالة عند التفاعل
Sidebar	أيقونات ملونة بخلفية شفافة عند عدم التحديد، وخلفية بنفسجية عند التحديد
Card	تصميم البطاقات يكون بظل خفيف shadow-md وحواف مستديرة rounded-2xl
Button	bg-[#5A47FF] text-white rounded-xl px-6 py-2 font-bold transition hover:bg-[#3f30cc]
Input	حواف ناعمة مع border بنفسجي باهت وتغيير لون عند الكتابة
